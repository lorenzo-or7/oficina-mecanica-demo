# TORQ — Automotive Service

Projeto demonstrativo de oficina mecânica da Or7.dev.

## Desenvolvimento

```bash
npm ci
npm run dev
```

## GitHub Pages

Publique no repositório `oficina-mecanica-demo` com **Settings > Pages > GitHub Actions**. O workflow publica automaticamente após o push na branch `main`.

URL: https://lorenzo-or7.github.io/oficina-mecanica-demo/

Fotos externas são carregadas pelo Unsplash e dependem de conexão com a internet.
